# Procedencia de los datos

Todos los registros incluidos en este repositorio son sintéticos y se utilizan
exclusivamente para practicar automatización de seguridad de forma segura.

- Los usuarios, hostnames, marcas temporales y eventos son ficticios.
- Las direcciones internas pertenecen a rangos IPv4 privados.
- No se incluyen credenciales, claves de API, datos personales ni malware activo.
- Los datasets iniciales son pequeños de manera intencionada y aumentarán en
  volumen, variedad y dificultad conforme avance el proyecto.
